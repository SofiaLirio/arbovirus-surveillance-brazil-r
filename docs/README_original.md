# Arbovirus Surveillance in Brazil — Normalized Analysis Pipeline

Reproducible statistical and geospatial analysis of **Dengue, Chikungunya, and Zika** notifications across the 27 Brazilian federative units, 2016–2025 (monthly grain). All inputs are normalized CSV fact/dimension tables; all outputs (tables, plots, composite figures) are generated by a single orchestrator.

- **Data window:** 2016–2025 (CHIKV starts 2017)
- **Spatial unit:** 27 federative units (UF)
- **Temporal unit:** monthly
- **Run date of the committed outputs:** 2026-10-01

A full narrative of the methods and findings is in [`RESULTS_SUMMARY.md`](RESULTS_SUMMARY.md) (and rendered as `RESULTS_SUMMARY.html`).

## Pipeline stages

`pipelines/run_all.py` executes these in order:

| # | Script | Produces |
|---|---|---|
| 1 | `arbovirus_pipeline_en.py` | Descriptives, Mann-Kendall trends, Spearman climate correlations, Global Moran's I |
| 2 | `arbovirus_geospatial.py` | Choropleth maps, LISA clusters, trend maps |
| 3 | `graphpad_to_python_pipeline.py` | Clinical / demographic plots from GraphPad `.pzfx` data |
| 4 | `bootstrap_ci.py` | Bootstrap 95% CIs alongside normal-approximation CIs |
| 5 | `glm_poisson.py` | Poisson GLM (pooled FE, per-state, lagged) |
| 6 | `glm_quasi_poisson.py` | Quasi-Poisson GLM |
| 7 | `glm_negbin.py` | Negative Binomial GLM (preferred model — see writeup) |
| 8 | `plot_glm_results.py` | `figures/glm_fig1`–`glm_fig5` (GLM IRR / AIC / forest plots) |
| 9 | `merge_figures.py` | 11 `figures/` composites (`Figure1`–`Figure8`; Figure 6 split into `Figure6a`–`Figure6d`) |

`pipelines/alt_results.py` is a separate, standalone regenerator for the
five alternative-view figures (`trend01_slope_first_last`,
`trend03_sen_dotbar`, `spat01_choropleth_facet`, `spat02_lisa_facet`,
`glm02_caterpillar_temp_irr`). It is not part of `run_all.py` — run it
on demand with `python pipelines/alt_results.py`; it writes to
`alt_results/`, and the curated copies in `figures/` are refreshed by
copying them over. See
[`alt_results/README.md`](alt_results/README.md) for what each alternative
replaces.

## Running the analysis

Requires Python 3.11+ (the pinned pandas 3 / NumPy 2.4 / SciPy 1.17 do not support 3.10). CI runs on 3.12.

```bash
pip install -r requirements.txt
```

Then:

```bash
cd pipelines
python run_all.py
```

All scripts read from `db/` and write to `outputs/` and `figures/` at the repository root (paths are resolved in `pipelines/data_loader.py`, so no symlinks are needed and the pipeline runs unchanged on Windows). The orchestrator reports `9/9 succeeded` on a clean run. Moran / LISA permutation tests use a fixed seed, so reruns reproduce the committed numbers.

## Key findings (one-line summary)

- **Dengue** dominates by volume (16.3 M cases), is the only arbovirus with significant spatial clustering (Moran's I = 0.52), and has a robust temperature association: IRR ≈ 1.4 per +1 °C above the seasonal norm (95% CI 1.18–1.70; NegBin with state + month fixed effects, cluster-robust SEs).
- **Chikungunya and Zika** show no significant climate association once seasonality and within-state correlation are accounted for.
- **No state-level Mann-Kendall trend survives FDR correction**; the southern Dengue/Chikungunya increases (RS, SC) are suggestive only (q ≈ 0.1).
- **Negative Binomial is the appropriate model family**; Poisson is rejected (dispersion 10×–44,000× the assumption).

Full numbers, CIs, and per-state breakdowns: [`RESULTS_SUMMARY.md`](RESULTS_SUMMARY.md).

## Methodological notes

1. The `Annual_Incidence` column in the source DB was actually *monthly* incidence per 100k — renamed to `Monthly_Inc_per100k`; values unchanged.
2. Both normal-approx and bootstrap (1,000 resamples) CIs are exported. Bootstrap is preferred for Dengue due to right-skew.
3. GLMs include month fixed effects. SEs are cluster-robust by state (pooled models) or HAC / Newey-West with 3 lags (per-state series); Quasi-Poisson uses Pearson-scaled SEs with t-based inference. NegBin α is estimated by profile likelihood (as R's `MASS::glm.nb`).
4. Every family of 27 state-level tests carries Benjamini-Hochberg q-values (`q_value`, `Significant_FDR`) next to the raw p-values.
5. Spatial weights: KNN k=5 on state polygon centroids, shared by both spatial stages.
6. Months with missing case counts are not treated as zero: annual totals are annualised over the months reported.
